# שבצ"ק מילואים — פלטפורמה לניהול שמירות

אפליקציית ווב בעברית לניהול שבצ"ק שמירות במילואים. תומכת בהגשת אילוצים על ידי החיילים, שיבוץ אוטומטי הוגן ותצוגה ויזואלית דמוית Excel.

## תכונות

- **2 עמדות שמירה** מאוישות 24/7
- **6 משמרות יומיות** של 4 שעות כל אחת (02, 06, 10, 14, 18, 22)
- **חיילים** - ניהול גמיש, כל חייל מקבל צבע ייחודי ומספר אישי
- **אילוצים** - חיילים מגישים בעצמם דרך קישור משותף `/c` + הזדהות בשם ובמספר אישי
- **שיבוץ אוטומטי** - אלגוריתם CSP עם backtracking + simulated annealing
  - מכבד אילוצים קשיחים (הקפדה על אילוץ + מנוחה של 8 שעות)
  - מאזן עומס (סה"כ שמירות, לילות, סופ"ש)
- **גרירה ידנית** - drag & drop של חיילים בין משמרות
- **תצוגת הדפסה** + ייצוא PNG בפורמט דמוי-Excel
- **תמיכה מלאה ב-RTL ועברית**

## הקמה והרצה

### דרישות מקדימות

- Node.js 18+
- pnpm (`npm i -g pnpm`)

### משתני סביבה (`.env`)

```env
DATABASE_URL="file:./dev.db"          # או postgres:// בפרודקשן
ADMIN_PASSWORD="..."                  # סיסמת מנהל ל-/admin
SESSION_SECRET="..."                  # מחרוזת hex אקראית לחתימת cookie של חיילים
```

ליצירת `SESSION_SECRET`: `openssl rand -hex 32`

### התקנה

```bash
# התקנת חבילות
pnpm install

# הקמת DB ו-seed עם חיילים מהשבצ"ק הקיים
pnpm prisma db push
pnpm db:seed

# הרצה במצב פיתוח
pnpm dev
```

פתח את הדפדפן בכתובת [http://localhost:3000](http://localhost:3000)

### Build לפרודקשן

```bash
pnpm build
pnpm start
```

## שימוש

### למנהל

1. כניסה ל-`/admin`
2. **ניהול חיילים** (`/admin/soldiers`) - הוספה, עריכת צבעים, העתקת קישורים אישיים
3. **שבצ"ק** (`/admin/schedule`) - בחירת שבוע, שיבוץ אוטומטי או ידני
4. **אילוצים** (`/admin/constraints`) - צפייה בכל האילוצים מצרפית
5. **הדפסה** - תצוגה ויזואלית להדפסה / ייצוא PNG

### לחייל

1. המנהל שולח קישור משותף יחיד: `/c`
2. בכניסה לקישור — החייל מזדהה בשם מלא + מספר אישי
3. לאחר הזדהות מוצלחת, מוצג טופס סימון משבצות לשבוע הפעיל:
   - **שחור** = לא יכול בשום אופן (אילוץ קשיח)
   - **ירוק** = יכול ורוצה (העדפה)
4. ניתן לערוך כל עוד חלון האילוצים פתוח ולא הוגש סופית
5. ההזדהות נשמרת ב-cookie למשך 8 שעות

## ארכיטקטורה

- **Next.js 14** (App Router) + TypeScript
- **Prisma + SQLite** - DB מקומי. לפרודקשן ניתן להחליף ל-Postgres ע"י עריכת `prisma/schema.prisma`

## אלגוריתם השיבוץ

המימוש ב-`src/lib/scheduler/solver.ts`:

1. **Backtracking + MRV** - שיבוץ קודם של המשמרות עם הכי פחות אפשרויות
2. **LCV** - בחירת החייל שמשאיר הכי הרבה גמישות
3. **Forward Checking** - הסרת חיילים מ-domains כאשר מנוחה לא מספקת
4. **Simulated Annealing** - שיפור אחרי שיבוץ ראשוני, מאזן הוגנות

### אילוצים קשיחים
- חייל לא משובץ בזמן אילוץ HARD
- מנוחה של 8 שעות (12 שעות בין תחילת משמרות)
- חייל לא משובץ בשתי עמדות באותה משמרת

### פונקציית מטרה (אילוצים רכים)
- שונות במספר שמירות לחייל (משקל 10)
- שונות בשמירות לילה (משקל 8)
- שונות בשמירות סופ"ש (משקל 8)
